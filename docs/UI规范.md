## 1. 设计基调

**主题**：东方玄幻 · 修仙 · 幽暗深邃

- **整体基调**：深色背景、低调的卡片浮层、五行/境界主题色点缀
- **视觉气质**：古朴、庄重、有"仙气"，避免花哨高亮
- **信息层级**：先卡片分组 → 再区块标题 → 再具体数据
- **1080p 竖屏**：设计基准 390×844，拉伸模式 `canvas_items + expand`

**不变量**
- 不使用图片/图标时用色块 + 文字表达，保持轻量
- 禁止大面积纯白或高饱和亮色背景
- 不可同时使用超过 3 种强调色（区块标题色不计数）

## 3. 字体与字号

默认使用系统默认 Unicode 字体（无自购字体时沿用 Godot 主题默认）。

| 层级 | 字号 | 示例 |
|------|------|------|
| 页面大标题 | 18 | 页面标题（如"洞府"） |
| 区块标题 | 14~16 | "── 建筑物 ──" |
| 卡片主标题 | 14 | 物品名、建筑名 |
| 卡片数据行 | 12 | 属性数值、价格 |
| 说明/描述 | 11 | 物品描述、注释 |
| 弱信息 | 9~10 | 标签、单位、脚注 |

**约定**：
- 正文一律使用 `add_theme_font_size_override("font_size", N)`
- 不使用默认大字号除非明确是 banner
- 数字统一用 12~14，重要数字用主题色

## 4. 基础组件

### 4.1 Label（文本）

推荐通过辅助函数创建（见 §12）：

```gdscript
_lbl("境界：练气一层", COLOR_MAIN, 14)
```

- 需换行文本使用 `autowrap_mode = TextServer.AUTOWRAP_WORD_SMART`
- 描述文本颜色统一 `#8A93A3`，字号 11

### 4.2 Button（按钮）

| 按钮类型 | 尺寸 | 字号 | 说明 |
|----------|------|------|------|
| 主操作 | 高度 30+ | 13~14 | 购买、开始、确认 |
| 次操作 | 高度 26 | 11~12 | 进入、升级、切换 tab |
| 危险操作 | 高度 26 | 11~12 | 逐出、兵解（文字用 `#E05555`） |
| 禁用态 | — | — | `disabled = true` |

- 返回按钮：文字统一为 `"← 返回"` 或 `"< 返回"`（当前两种混用，规范统一为 **`"← 返回"`**），字号 14
- 通用按钮文字用简短动词，避免长句

### 4.3 ProgressBar（进度条）

- 非法相/战斗中，统一：`min=0`，`show_percentage=false`，默认高度 10~16
- 进度条填充色可按内容主题（如炼丹橙色、HP 红色/绿色）

### 4.4 Separator（分隔线）

- 区块之间用 `HSeparator.new()`
- 不需要额外样式，使用主题默认

## 5. 卡片组件

卡片是信息展示的基本单元，用于把相关数据分组。

### 5.1 卡片规则

| 属性 | 标准值 |
|------|--------|
| 圆角 | **统一 6**（content 卡片） / 4（小格子） |
| 左右内边距 | **10** |
| 上下内边距 | **6** |
| 背景 | 见 §2.1 卡片底色 |
| 次要边框（可选） | 1px，色 = 卡片强调色*0.6 |

> 历史混用了 4/5/6，**统一收口到 6**。

### 5.2 卡片三态配色（用于商城/可购买物）

| 状态 | 底色 |
|------|------|
| 未拥有·可购买 | `#161C22` |
| 已拥有/已习得 | `#142019`（带绿底倾向） |
| 灵气不足 | `#1C1212`（带红底倾向） |

### 5.3 卡片内部布局（标准模板）

```
PanelContainer（卡片）
└─ HBoxContainer
   ├─ VBoxContainer (SIZE_EXPAND_FILL)
   │  ├─ Label   // 名称（品级/主题色）
   │  ├─ Label   // 描述（次级色, 11, autowrap）
   │  └─ Label   // 额外信息（弱色, 10）[可选]
   ├─ Label+Label // 价格/数值区 [可选]
   └─ Button      // 操作按钮（右对齐）
```

## 6. 页面框架结构

所有功能面板必须遵循统一骨架：

```
PanelContainer（根，PRESET_FULL_RECT）
└─ VBox
   ├─ TopBar (HBox)
   │  ├─ Button("← 返回")
   │  └─ Label(页面标题, 居中, 18)
   ├─ [HBox 标签栏]（可选）
   ├─ HSeparator
   └─ ScrollContainer (SIZE_EXPAND_FILL)
      └─ VBoxContainer(ItemList)
```

**注意**：`TopBar` 返回按钮在左、标题居中，若 tab 栏存在则返回按钮在左、tab 居中、标题在右（参考宗门面板）。统一采用**宗门面板**的三段式布局：

```
TopBar
├─ Button("← 返回")     // 左
├─ HBox(TabBar) 居中      // 中
└─ Label(标题) 右          // 右expand
```

### 6.1 页面可见性

- 面板在场景中默认 `visible = false`
- 由 `main_ui.gd` 的 `show_panel()` 统一控制切换
- 新面板需在 `show_panel()` 中追加对应行

## 7. 导航与标签

### 7.1 顶部 Tab 标签（如法相"管理/图鉴"、宗门"建筑/弟子"）

- 使用 `HBoxContainer` 居中，间距 `4`
- 普通态文字色 `#808080`，激活态主题色 `#FFD54A`（金色）
- 通过 `add_theme_color_override("font_color", ...)` 切换，不使用 toggle button 高亮背景

### 7.2 左侧分类菜单（如商店"全部/功法/丹方/装备..."）

- 使用 `VBoxContainer` + `toggle_mode` 按钮，宽 60~64
- 激活态：`button_pressed = true`

## 8. 按钮规范

| 场景 | 按钮文字风格 | 示例 |
|------|-------------|------|
| 购买 | 动词 | "购买" |
| 已拥有 | "已习得" / "已拥有" + disabled | — |
| 条件不足 | "境界不足" + disabled | — |
| 升级 | "升级"+显示价格 | "升级（1,000灵）" |
| 返回上级 | "← 返回" | — |
| 危险 | "兵解重修" / "逐出"（红字） | — |

**按钮禁用时机**：灵气不足 / 境界不足 / 已拥有 / 正在冷却时，一律 `disabled=true`，并配合 toast/日志说明原因。

## 9. 弹窗规范

### 9.1 Modal 弹窗（覆盖层）

（参考地图"设置"、炼丹"选择丹炉"）统一采用：

```
Control(overlay, FULL_RECT, z_index=100)
├─ Panel(bg, 半透明黑 Color(0,0,0,0.5), 点击关闭)
└─ CenterContainer
   └─ PanelContainer(卡片, 深色带边框)
      ├─ Label(标题, 16)
      ├─ HSeparator
      ├─ 内容
      └─ Button("关闭")
```

- 弹窗卡片底色：`#1A1F26`，边框收敛圆角 8
- 点击遮罩空白处关闭
- 同一面板同时只允许一个弹窗（用 `_popup` 引用释放）

### 9.2 确认弹窗

- 危险/不可逆操作必须用 `ConfirmationDialog`（如兵解重修）或模态确认
- 明确列出后果

## 10. Toast 提示规范

统一实现一份可复用的 Toast（避免各面板重复复制代码）。

| 属性 | 标准 |
|------|------|
| 位置 | 顶部居中偏下（offset_top 56~102） |
| 背景 | `#0F1A0F`（alpha 0.95），圆角 10，边框 1px |
| 文字 | 居中，字号 14 |
| 时长 | 淡入 0.15s → 停留 1.35s → 淡出 0.4s（总计 ~1.9s） |
| 边界色 | 跟随内容色（成功绿/失败红/普通） |

**规范要求**：
- 新建独立 `ui_components/toast.gd`（或全局单例），**面板内不再各自实现**
- Toast 用于短暂/瞬时反馈；长期状态变化用系统日志 `log_message()`

## 11. 数字与数据展示

### 11.1 大数据格式化

统一使用万进制中文单位：

```
< 10000   → 正常千分位（如 "12,345"）
>= 10000  → "1.2万" "3.4亿" "56兆" ...
```

单位序列：`万、亿、兆、京、垓、秭、穰、沟、涧、正、载、极`

> **注意**：本项目两种格式化并存 —— 千分位 `_format_num()` 与中文单位 `_format_big()`。
> **规范**：属性/数值用中文单位 `_format_big()`；具体小数值（<1万）用普通整数。统一使用 `_format_big()`，并删除重复的本地 `_format_num`/`_fmt`。

### 11.2 数值颜色语义

| 数值类型 | 颜色 |
|---------|------|
| 金钱/灵气 | 金色 `#FFD54A` |
| HP | 绿（友）/红（敌） |
| 攻击 | 红橙 `#FF8A66` |
| 防御 | 蓝 `#6EBFF0` |
| 灵力产出 | 金色 |

## 12. 通用辅助函数（代码规范）

为避免各面板复制粘贴，**统一在共享基类或工具脚本中封装**，所有面板通过相同函数名使用：

### 12.1 推荐的统一函数签名

```gdscript
# 统一命名（替换当前混杂的 _pl / _lbl / _wlbl / _label）
func _lbl(text, color = Color("#E8EAF0"), size = 12) -> Label

# 卡片背景（替换 _make_card / _make_card_bg / _card_bg）
func _card_bg(color = Color("#1A1F26"), radius = 6, border = null) -> StyleBoxFlat

# 数字格式化
func _format_big(n) -> String      # 中文单位
func _format_num(n) -> String      # 千分位

# 区块标题
func _section_title(text, color = Color(0.3, 0.8, 1.0)) -> Label
```

### 12.2 命名统一映射表（历史遗留 → 标准）

| 历史（废弃） | 标准 |
|------------|------|
| `_pl()` / `_make_label()` | `_lbl()` |
| `_wlbl()` / 手动 autowrap | `_lbl()` + autowrap |
| `_make_card()` / `_make_card_bg()` / `_card_bg()` | `_card_bg()` |
| `_fmt()` / 本地 `_format_big` | `_format_big()` |

> 注：`_format_big` 函数为通用工具，应提取到单例/静态工具类，各面板 `BIG_UNITS` 常量不再各自声明。

## 13. 代码结构约定

### 13.1 面板文件组织

```
scenes/
  xxx_panel.tscn          # 面板场景
scripts/
  xxx_panel.gd            # 面板脚本（extends PanelContainer）
ui_components/            # [新] 共享组件
  toast.gd
  ui_common.gd            # [新] UI 通用辅助函数/常量/单例
```

### 13.2 面板脚本结构（自上而下）

```
信号声明 (signal ...)
常量 (COLOR_*, 数据定义)
私有数据变量 (_xxx)
static/通用辅助 (set_state)
生命周期 (_ready, refresh)
UI 构建函数 (_build_xxx / _make_xxx_card)
事件处理 (槽函数)
```

### 13.3 信号通信约定

- 面板**不直接引用 main_ui 或其他面板**，一切通过 `signal` 向上层（main_ui）报告
- `main_ui.gd` 负责数据状态与面板 `set_state()` 传递
- 命名：事件触发一律 `xxx_requested`（如 `buy_skill_requested`、`back_requested`）

### 13.4 命名规范

| 类别 | 命名 | 示例 |
|------|------|------|
| 信号 | 小驼峰 + `_requested` | `upgrade_building_requested` |
| 函数 | 下划线小驼峰 | `_build_building_card` |
| 常量 | 全大写下划线 | `COLOR_GOLD`, `BUILDING_DEFS` |
| 私有变量 | 下划线小驼峰 | `_current_tab` |
| 数据字典键 | 小驼峰 | `min_realm`, `base_cost` |

## 14. 新面板开发清单

开发一个新功能面板时，**按此检查表逐项核对**：

- [ ] 场景根节点为 `PanelContainer`，`FULL_RECT`
- [ ] 骨架遵循 §6 页面框架
- [ ] TopBar 返回按钮 `"← 返回"` + 居中标题（18号）
- [ ] 有 tab 时采用三段式 TopBar（§6）
- [ ] 卡片圆角统一 6、边距 10/6（§5）
- [ ] 文本使用《UI规范》色板（§2.1/2.2），禁止裸用随意色值
- [ ] 数字用 `_format_big()`（§11）
- [ ] 使用统一辅助函数 `_lbl()` `_card_bg()`（§12）
- [ ] 面板默认 `visible=false`，已接入 `main_ui.show_panel()`
- [ ] 与主逻辑通过 signal 通信，不直接触碰 main_ui 数据（§13.3）
- [ ] 可逆按钮有禁用态 + 明确文案（§8）
- [ ] toast 反馈通过共享组件（§10）
- [ ] 不显式声明重复的 `BIG_UNITS` / `_format_big`（用共享工具）
- [ ] 新面板场景已打入 `show_panel()` 映射

## 附：最终视觉验收标准

1. 打开任意面板，背景为深色系，无刺眼亮白
2. 卡片间距均匀，圆角一致（6）
3. 标题、价格、属性颜色符合语义
4. 按钮状态（可点/禁用/已拥有）区分清晰
5. 数字使用中文单位，无超长数字溢出
6. 从菜单进入任何二级页面，返回按钮均可用
